# Traditional OOP Practice Series in Python

A hands-on Python laboratory exploring foundational and advanced Object-Oriented Programming (OOP) concepts, design patterns, and clean code principles.

## 📌 Concepts Covered
- **Encapsulation & Abstraction**: Classes, instance methods, and private attributes.
- **Inheritance & Polymorphism**: Method overriding, `super()`, and class hierarchies.
- **Composition over Inheritance**: Modular class composition patterns.
- **Decorators**: Function and method decorators, property getters/setters (`@property`).

## 🛠️ Tech Stack
- **Language**: Python 3

## 💻 Running the Code
```bash
python app.py
```
